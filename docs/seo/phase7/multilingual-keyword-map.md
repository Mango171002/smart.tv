## 6. Rules for every language

- One H1 per page, matching the title's topic; no keyword repetition.
- The word « IPTV » only in informational, neutral content (definitions, comparisons, technical help) — never in
  titles promising channels, sports or films.
- Titles ≤ 60 characters and descriptions ≤ 155 characters, checked by unit tests per language (as for 5C).
- Localised units and examples (Mbit/s, local ISP/router vocabulary), local consumer-rights wording (reviewed).
- Each article links to at least one Help topic and to the trial; each Help topic links back to related articles.
